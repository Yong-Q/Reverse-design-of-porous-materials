# Introduction  

Contains the code of HOF theoretical database construction and reverse design materials, as well as the data of the database  

*****Active-learing-NA*****  
A co-iterative training process involving reverse design materials and cdft calculations  

*****HOFmake*****  
bbs materials containing HOF materials and multi-process methods to build HOF materials, bbs as an example, more please look forward to the following...  

*****SISSO-LASSO*****  
Some implementation code  

*****Calculated-data*****  
The calculated data is available for machine learning  

*****Structure-file*****  
Subsequent upload
